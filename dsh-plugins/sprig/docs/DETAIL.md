# 知枝选词解释

在 DSH 对话里选中文字后，原来的「引用」操作条会变成 **复制 / 引用 / 用知枝解释** 三个按钮，不再额外弹一个和原生 Copy 重叠的右键菜单。

- 插件只读取选中文字，以及选中消息前后各最多一条**真实用户/助手消息**；系统注入的 `<system-reminder>`、技能清单、context 节点会被过滤，上下文总长 ≤1800 字。
- 通过本机 `127.0.0.1:53917` 的 bridge 发送给 **正在运行的知枝**，由知枝建卡并流式解释。
- 不会把内容上传到第三方；上下文只在本机 DSH 和知枝之间传递。

## 前置条件

1. 知枝已启动（菜单栏有图标）。
2. 知枝设置里启用了「启用跨应用划词」。
3. 选中 DSH 中已展示的用户内容或已完成的 Assistant 文本；工具、注入上下文、流式输出不参与选区交互。

## 限制

- 这是 DSH Client 插件，只出现在 Web UI；终端/CLI 不生效。
- 知枝退出后按钮会提示「知枝未运行」，重试即可。
